# Tint-able Firework Rocket

A Minecraft Client-side mod on Fabric
that provides color tints for firework rocket.

## Variants

### Flight duration

- 1 second<br>
  ![Flight Duration 1](md-resource/duration_1.png)


- 2 seconds<br>
  ![Flight Duration 2](md-resource/duration_2.png)


- 3 seconds<br>
  ![Flight Duration 3](md-resource/duration_3.png)

### With firework stars

- Contains blue firework star, 1 second flight duration<br>
  ![Star color blue](md-resource/blue_without_fade.png)


- Contains white firework star fade to red, 2 seconds flight duration<br>
  ![Star color with fade](md-resource/white_to_red.png)


- Multiple firework stars, red + blue + white<br>
  ![Multiple firework stars](md-resource/multiple-firework-stars.gif)

Any resources are available under [`tintable-firework-rocket`](src/main/resources/assets/tintable-firework-rocket) namespace,
and you can modify using resource pack feature.

## Installation

Supports on [Fabric](https://fabricmc.net/use/) and requires [Fabric API](https://modrinth.com/mod/fabric-api).

[Modrinth Project page](https://modrinth.com/project/tint-able-firework-rocket) is available to download this mod.
